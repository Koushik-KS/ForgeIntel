# ForgeIntel

AI-powered product intelligence platform for data enrichment and validation.

## Features

- Add and manage products
- Generate product intelligence
- Extract and validate product attributes
- Confidence-based review
- Edit, accept, or reject attributes
- Evidence and traceability
- Product dashboard and analytics
- Product deletion

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Vercel
- Render
